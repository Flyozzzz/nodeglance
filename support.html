Nodeglance Support

Write to flyoz@vk.com or open a request on GitHub. We usually answer within a few days.

The server shows “authentication failed”

Check the user name and the password or the Ed25519 private key. After a failed login Nodeglance stops retrying that connection to protect you from lockouts; edit the connection or press Refresh to try again.

“The SSH host key has changed”

The server presented a different identity than the one you trusted. If you reinstalled it, delete the connection and add it again; otherwise verify the server independently.

Monitoring needs a Linux server

Direct SSH monitoring reads /proc and standard POSIX tools. Other systems can be monitored through a Beszel hub.
